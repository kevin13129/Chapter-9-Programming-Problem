# Journal
In this phase I created a backpack with smaller bags and items inside it. I noticed that getWeight() works the same way even when bags are inside other bags. If I wanted to add something like a WeightlessBag, I could create a new class that extends InventoryComponent and changes how weight is calculated without modifying the existing Item or Bag classes. This follows the Open-Closed Principle because we're adding new behavior instead of changing existing code.
